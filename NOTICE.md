# GLC-PTCGO notices

GLC-PTCGO is a Pokémon Trading Card Game Online (PTCGO) private server built
for the **Gym Leader Challenge (GLC)** format.

## Credits

GLC-PTCGO is a modified version of earlier open-source work:

- **Spirit-PTCGO** by Bratah123, the original Python PTCGO server emulator:
  <https://github.com/Bratah123/Spirit-PTCGO>
- **CompletePTCGO** by dragokai180, the community fork of Spirit-PTCGO that
  GLC-PTCGO started from: <https://github.com/dragokai180/CompletePTCGO>

GLC-PTCGO has since been heavily modified: GLC-only card pool and format
rules, card effect fixes and test coverage, gameplay, reconnect and
disconnect handling, and server tooling. Thank you to the authors and
contributors of both projects.
